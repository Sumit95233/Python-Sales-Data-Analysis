# Python Sales Data Analysis

## Project Overview
Sales Analyzer is a Python-based Data Analysis project that analyzes sales transaction data to extract meaningful business insights.

The project uses Python programming concepts to calculate revenue, analyze product performance, identify top customers, and understand sales trends over time.

## Objectives
- Analyze overall sales performance.
- Calculate total revenue and orders.
- Identify the best-selling products.
- Analyze category-wise and product-wise revenue.
- Identify the highest-spending customer.
- Analyze daily sales revenue.
- Calculate revenue within a specific date range.
- Export category-specific sales records into a separate CSV file.

## Key Features
1. **Total Revenue Analysis:** Calculates overall revenue using quantity and price.
2. **Order Analysis:** Counts the total number of orders.
3. **Quantity Analysis:** Calculates the total items sold.
4. **Category Analysis:** Calculates revenue generated by each category.
5. **Product Analysis:** Evaluates revenue generated by individual products.
6. **Best-Selling Product:** Identifies the product with the highest quantity sold.
7. **Customer Analysis:** Identifies the customer who spent the most.
8. **Daily Sales Analysis:** Calculates revenue for each date.
9. **Date Range Analysis:** Calculates revenue between two user-provided dates.
10. **CSV Export:** Exports all Electronics category orders into a separate CSV file.

## Technologies Used

## How to Run the Project

1. Clone this repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/Python-Sales-Data-Analysis.git
   ```

2. Navigate to the project folder:
   ```bash
   cd Python-Sales-Data-Analysis
   ```

3. Install Jupyter Notebook:
   ```bash
   pip install notebook
   ```

4. Launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```

5. Open `SalesAnalyzer.ipynb` and run the cells.
